# Lasses træningsplan 📅

Oversigt over ugens træning til telefonen: ugeplan, styrkeprogram og intervalmetoder. Opdateres automatisk én gang om ugen.

**Læg den på hjemmeskærmen:** åbn siden i Safari → Del → "Føj til hjemmeskærm" (Android/Chrome: ⋮ → "Føj til startskærm"). Den virker også offline.

## For udviklere
```bash
npm install
npm run dev     # lokal udvikling
npm run check   # typecheck + tests + build + browsertests
```

Ugeplaner ligger i `src/data/weeks/` – én JSON-fil pr. uge.
